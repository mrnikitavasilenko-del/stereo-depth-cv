# Stereo Depth Reconstruction

Восстановление карты глубины по стерео-видео двумя методами:
- **Классический** — калибровка камер + SGBM-диспаритет + WLS-фильтр
- **Нейросетевой** — MiDaS (monocular depth estimation)

## Что за проект

Стерео-камера на Raspberry Pi (два объектива, база 17 см) снимает видео в формате **side-by-side (SBS)** — левый и правый кадр склеены в одно изображение. Задача — по этому видео получить карту глубины и сравнить два подхода.

```
Исходное SBS-видео  →  разрезать  →  левый кадр | правый кадр
                                           ↓
                              алгоритм: SGBM + WLS-фильтр → карта глубины (метрическая)
                              нейросеть: MiDaS             → карта глубины (относительная)
                                           ↓
                                    сравнение рядом
```

## Структура директорий

```
.
├── chess/                   # SBS-видео с шахматной доской (для калибровки)
├── strereo/                 # SBS-видео сцены (для карт глубины)
├── calibration/             # результаты калибровки (.npz)
├── 01_extract_frames.py     # шаг 1: извлечь кадры из видео
├── 02_calibrate.py          # шаг 2: стерео-калибровка
├── 03_classical_depth.py    # шаг 3: классическая карта глубины
├── 04_neural_depth.py       # шаг 4: нейросетевая карта глубины
├── 05_compare.py            # шаг 5: коллаж для сравнения
└── requirements.txt
```

После запуска появятся:
```
frames/
├── chess/left/  chess/right/     # кадры для калибровки
└── scene/left/  scene/right/     # кадры сцены
results/
├── classical/                    # SGBM карты (JET colormap)
├── neural/                       # MiDaS карты (MAGMA colormap)
└── comparison/                   # коллажи: оригинал | SGBM | MiDaS
```

## Требования

- Python 3.8–3.12 (рекомендуется 3.11)
- NVIDIA GPU — опционально, но сильно ускоряет нейросеть

> ⚠️ Python 3.14 не поддерживается CUDA-сборками PyTorch — нейросеть будет работать на CPU.

## Установка

```bash
pip install -r requirements.txt
```

Если есть NVIDIA GPU (CUDA 12.4):
```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
```

Без GPU (CPU-режим, работает медленнее):
```bash
pip install torch torchvision
```

## Запуск

### Шаг 1 — Извлечь кадры из видео

```bash
python 01_extract_frames.py
```

Разрезает SBS-кадры пополам → `frames/chess/` и `frames/scene/`.

Настройки в файле:
```python
CHESS_STEP = 3   # шаг извлечения кадров для калибровки (меньше = больше кадров)
SCENE_STEP = 1   # шаг для сцены (1 = каждый кадр)
```

---

### Шаг 2 — Калибровка камер

```bash
python 02_calibrate.py
```

Находит углы шахматной доски (9×6 внутренних углов, клетка 35 мм), калибрует каждую камеру отдельно, затем стерео-калибровку. Сохраняет матрицы и карты ректификации в `calibration/stereo_calib.npz`.

Хороший результат: **ошибка репроекции < 1.0 px**.

Если доска не найдена — попробуй уменьшить `CHESS_STEP = 1` в шаге 1.

---

### Шаг 3 — Классическая карта глубины

```bash
python 03_classical_depth.py
```

Pipeline:
1. Ректификация (устранение дисторсии и выравнивание строк)
2. CLAHE — усиление контраста
3. SGBM — поиск диспаритета в обоих направлениях
4. WLS-фильтр — сглаживание с учётом краёв, заполнение дыр
5. EMA (α=0.4) — временное сглаживание между кадрами
6. Перевод в глубину: `Z = f × B / d`  (f=792 px, B=0.17 м)

Результат: метрическая глубина в метрах, цвет JET (🔴 близко → 🔵 далеко).

Параметры для тонкой настройки:
```python
NUM_DISPARITIES = 128   # диапазон поиска (кратно 16)
BLOCK_SIZE      = 7     # размер блока (меньше = деталей больше, шума больше)
WLS_LAMBDA      = 8000  # сила сглаживания WLS
WLS_SIGMA       = 1.5   # чувствительность к краям
EMA_ALPHA       = 0.4   # плавность между кадрами (0=мягко, 1=без сглаживания)
```

---

### Шаг 4 — Нейросетевая карта глубины

```bash
python 04_neural_depth.py
```

Использует MiDaS через `torch.hub`. Модель выбирается автоматически:
- **DPT_Large** — если есть CUDA (лучшее качество)
- **MiDaS_small** — если только CPU (быстрее, каждый 5-й кадр)

При первом запуске скачает модель (~82 МБ).

Результат: относительная глубина (не метрическая), цвет MAGMA.

---

### Шаг 5 — Сравнение

```bash
python 05_compare.py
```

Создаёт коллажи в `results/comparison/`:

```
[ оригинал (левый кадр) | SGBM глубина | MiDaS глубина ]
```

Смотреть: открыть любой файл `results/comparison/XXXX_compare.png`.

## Сравнение методов

| | Классический (SGBM+WLS) | Нейросетевой (MiDaS) |
|---|---|---|
| Глубина | **метрическая** (реальные метры) | относительная |
| Качество на размытых кадрах | хуже | лучше |
| Скорость | ~5 мин / 1194 кадра (CPU) | ~8 мин / 239 кадров (CPU) |
| Требует калибровки | да | нет |
| Работает с одной камерой | нет | **да** |
